已确认：只增加一个“关键帧”分区。

数据设计：旧 `keyframes.first/last` 保持自动首／尾锚定；新增 `keyframe_points` 列表保存用户设定的绝对秒数和图片。可保存越界草稿，生成预检／运行时单独阻止无效 Guide，防止缩短时长后无法保存或调整。

修改时长时首尾帧保留其图片与身份，尾帧跟随新的镜头结尾，不转成普通关键帧。中间关键帧保留原秒数，超出新时长时进入越界区并提示调整，不自动删除、移动或压缩。

显示范围取镜头时长与最远关键帧的最大值，整体缩放到当前面板宽度。例如12秒改成10秒，仍有12秒关键帧时，0～12秒完整可见，10～12秒标为越界区；只调整显示比例，不改关键帧秒数。窗口变窄时同样重新适配，卡片与加号按钮均保留边距。

首尾帧固定在紧邻时间刻度的底层，其余关键帧发生重叠时仅向上叠加；保留稳定排布及边界缓冲，避免轻微拖动反复换层。分层仅影响界面，不改变时间、图片引用或生成顺序。按钮文案为“使用上段尾帧画面作为此段首帧”。

前后插帧加号完整放入图片框内，同层112像素卡片中心最小间距116像素，图片间保留4像素；回落换层额外保留8像素缓冲。加号不再占用卡片外侧空间，不改变图片预览、拖动和前后插帧的含义。

图片框底部提供“替换”，通过选图更换图片并保留关键帧 ID 和秒数，右上叉号仍用于删除关键帧或清除首尾帧。提示词接收素材卡及当前关键帧的复制引用，兼容图片同时携带 Files 与内部 MIME；素材卡支持复制引用和库内移动。全页文件导入仅在素材库节点或明确打开的素材编辑对话框内处理，导演台空白和提示词区域不执行入库。

“使用上一段尾部视频作为运动引导”为可切换按钮，复用现有无损运动衔接及全局上下文帧数、音频设置。首个镜头禁用；其余镜头取当前排列的上一镜头。开启后首帧槽显示视频引导占位，原首帧图片暂停参与条件和提示词图片引用，关闭引导或点击占位的叉号可恢复原首帧；选择上段尾帧图片或拖入新图片时退出运动引导。中间和尾部时间锚点按裁掉参考头之后的此段时间定位，高清二采保留相同位置。已有上段缺少所需无损衔接缓存或仍采用旧关键帧时间轴时，预检要求重新生成上段。运动衔接链使用精确帧位置并裁切，不将额外缓存帧压缩进交付视频。

镜头列表右键菜单支持“复制镜头”，副本紧随原镜头插入并选中，保留提示词、参考、关键帧、时长、种子和后处理设置；新编号独立，下一次种子与输出缓存不继承。编辑副本不修改原镜头，支持撤销复制。

图片预览点击外侧空白或关闭按钮可关闭，点击图片保留预览。时间轴图片本身作为 Guide，不自动占用 Picture 编号；显式在提示词里引用后，同时成为普通图片参考并取得 Picture 编号，素材无需进入素材库。

预览窗口按当前面板的可用宽高统一适配，读取原图，大小图片均等比放入同一预览区域；小图允许放大，竖图和宽图留边完整显示，切换图片不再随原始像素大小改变弹窗尺寸。

上段尾帧预览按视频路径及文件版本缓存原尺寸 PNG，并共享给首帧画面和运动引导；缩略图从缓存原图派生，并发访问只解码一次，视频更新更换缓存版本。版本明确的图片允许浏览器复用；弹窗换源期间隐藏旧图并显示加载状态，避免闪回原首帧。两种模式均可点击查看最尾帧，框内及大图分别标注“上段尾帧画面”“上段尾部引导”；运动引导生成仍使用潜空间衔接，预览不改变生成输入。

直接上传的首尾帧和中间关键帧均随本地项目保存及完整项目 ZIP 收录。新文件按 `media/assets/类别/`、`media/keyframes/镜头ID/` 分类，重复源文件只收录一次；已有托管文件不强行搬动。导入时恢复图片路径并保留时间与引用 ID。ZIP 不收录模型、缓存或生成成品，运动衔接所需缓存仍须在目标机器生成。
