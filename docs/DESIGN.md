# 架构与状态规则

导演台只公开工作站与素材库两个 ComfyUI 节点，管理项目、素材、分镜、任务和结果版本。`pipeline.json` 是工作站内部的执行配置，不是可导入的实体工作流。H3 条件、二采、修脸、实时预览与解码来自包内 `vendor/h3` 私有实现；工作站直接执行，不把辅助步骤注册到 ComfyUI 或展开成额外画布节点。ComfyUI 自带的基础采样类继续使用其原生实现。

## 项目与引用

项目和素材使用稳定 ID。素材名称用于显示和查找，提示词中的引用转换为稳定 ID，再按当前镜头实际使用顺序编译为 H3 媒体标签。素材缺失在预检阶段明确报告；导入不会静默清空已有素材库。

纯文字素材引用展开为文字内容。人物、场景和物品图片的描述只有勾选注入时才追加到图片标签后。人物绑定的音色作为音频依赖传入；提示词中已明确引用该音色时不额外追加，遗漏时在人物图片标签后追加实际音频标签。编译器不猜测说话者编号。

## 生成与结果

后台批次串行提交镜头，阶段为一采、高清二采和人脸修复。每个阶段完成后保存成品与版本索引。界面只接受对应任务和版本的结果，旧请求不能覆盖新结果。一采重生成期间不会把旧成品伪装成当前任务已完成的视频。

浏览器刷新后通过后台任务记录恢复状态；采样预览帧可能丢失，下一次预览或阶段结果会更新。服务进程退出后不会假装 GPU 任务仍在执行，已经保存的项目与成品保留。

原生右上角“运行”生成当前选中镜头，并按其二采／修脸设置执行；后端清除来自旧工作流的过期执行范围与请求标识，将实际执行登记到同一任务状态，更新预览、结果和种子。正在执行的任务可以通过指定 prompt ID 停止，已有视频与缓存保留；尚无前段结果的依赖任务按取消确认范围跳过，其他可执行任务继续。

运动引导的一采参考来自前段输出绑定的基础 latent 版本，二采保护头来自前段输出绑定的最终 latent 版本。衔接窗口按原生解码时间相位和交付末尾计算，保护头与分格的采样遮罩、模型遮罩一起裁剪。缺失或不匹配的缓存在采样前报明原因，不从压缩成品反推无损数据。最终 latent 与输出版本一起登记，可在缓存管理中独立清理；清理不删除成品。

## 参数和参考变化

镜头自身提示词、种子、时长、输入模式、素材内容和后处理需求用于判断镜头是否需要更新。外部模型或 LoRA 改动不把全部镜头标为参数修改，但执行缓存仍需满足真实生成条件。

改动判定只比较明确的用户设置：时长、当前种子、提示词、输入模式、连续性模式/参考镜头/选定帧、首尾帧、实际使用的素材文件或参考片段/文字描述/音色绑定、二采与修脸开关、启用修脸时的人数，以及无字幕/无背景音乐选项。关闭功能后的残留字段和缺省值补齐不算改动。素材改名、缩略图、文件时间戳、画布和参考尺寸、工作流节点参数、编译器自动生成字段不进入此判定。内部执行缓存使用另外的严格指纹。

改回原设置会清除提示。切换输入模式不会把随模式自动增删的素材、尺寸和连续性展开字段另报为多项修改。旧记录无法恢复明确参数基线时，不凭不透明的缓存哈希推测镜头已修改。

普通连续性引用前段新的一采画面时单独提示参考变化，不触发继续生成全部；前段仅二采或修脸不改变基础画面版本。动态上段尾帧作为首帧时属于实际生成输入，其变化纳入更新判定。

关闭二采/修脸选项不自动降级已有成品。新增后处理在条件匹配时复用基础缓存。明确重新生成当前镜头才会重做一采，并按选项继续后处理。

去漂移是默认关闭的运动引导测试选项。仅改变去漂移选择时可复用当前显示成品对应的一采缓存进行单独二采／修脸；后处理成功后确认当时选择，消除这项提示，但不篡改实际一采参数和版本。后续再修改该选项仍正常提示。

## 文件边界

`data/` 是本机运行数据，禁止进入源代码仓库。项目包包含配置和素材，不包含模型、生成视频或辅助 latent 缓存。当前不提供未经作者确认的示范工作流。视频由包内 PyAV 编码实现保存为 H.264/AAC MP4；导出已有镜头或合并全片仍由工作站执行，不依赖其他视频节点插件。

第三方连续性适配集中在 `vendor/aimixer`，保留原版权和 Apache-2.0 许可。其余源码使用项目根目录的 MIT 许可。
