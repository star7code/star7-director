# 本地文件管理

节点根目录中的 `.py`、`pipeline.json`、`web`、`vendor`、`schemas`、`workflows` 是程序与模板，不应手工清理。`docs` 是说明，`tests` 是开发回归脚本；测试生成的截图、日志和视频可以清理，历史 GPU 测试结果文件不是运行必需品。

日常项目采用“一项目一文件夹”：`data/projects/<项目ID>/`。文件夹名称使用稳定 ID，项目显示名称在界面中修改，避免重命名目录破坏已有索引。

| 项目文件夹内 | 用途 |
| --- | --- |
| `project.json` | 已保存的项目、分镜、种子、设置与工作流 |
| `state.json` | 生成运行状态与兼容读写快照 |
| `index.sqlite3` | 仅此项目的视频版本、缓存版本和成片索引 |
| `media/` | 本项目素材和缩略图归档 |
| `cache/` | 本项目二采、修脸辅助缓存 |
| `batches/` | 本项目后台任务和恢复进度记录 |
| `previews/` | 本项目可复用的临时连续预览；新版成功后清理旧版 |

`data` 根目录的共享服务目录不存独立项目：`media` 是上传／旧引用兼容区，`packages` 是打包临时区，`logs` 是运行和维护日志，`project-trash` 是项目回收区。这些不能混作某个项目的成品目录。项目创建后素材归入其自己的 `media`。

旧的根目录索引、项目 JSON、任务和预览记录会迁移到各自项目目录，索引迁移前留一份数据库备份在 `logs`，不会重新创建根目录项目索引。删除项目移走完整项目文件夹，正式视频保留。

正式生成与导出视频在 ComfyUI 的 `output/Star7-Director/年月日`，不在辅助缓存中：

- `S7D-时间戳-shot_xxx`：生成版本，更新版本带 `-2`、`-3` 等。
- `S7D-时间戳-shot_xxx-export`：单镜头导出副本。
- `S7D-时间戳-final-film`：合并导出的成片。

本地另存为保留视频路径索引并复制素材和辅助缓存，不复制视频；导出的项目 ZIP 包含素材和分镜设置，不包含成品和辅助缓存。

源码发布和 Git 更新不包含此数据目录。更新时保留已有项目、素材和成品。
