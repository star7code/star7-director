<h1 align="center">Star7 导演台 · Star7 Director</h1>
<p align="center">在 ComfyUI 画布里管理素材、分镜、生成队列和镜头版本。</p>

## 发布状态

首个正式版本仍在整理和验证。此前上传的 `v0.1.0` 是未经确认的开发快照，不是最终第一版；其中的旧开发工作流已经从仓库移除，不应作为正式使用示例。真正的示范工作流将由项目作者确认后另行提供。

本次只纠正项目说明并移除旧示例；独立后端重构完成后，代码更新和正式发布仍需项目作者确认。

## 两个节点

导演台的正式公开入口只有：

- **导演台工作站 — Star7**：分镜、镜头设置、生成队列、预览、二采、修脸和视频导出。
- **项目素材库 — Star7**：人物、场景、物品、音色、视频与文字素材管理。

旧的条件桥、缓存保存/载入、完成记录和导出辅助节点不作为公开节点或使用步骤，也不提供展开这些节点的工作流模板。

## 独立实现

目标结构是在导演台包内提供 H3 条件处理、采样调度、高清二采、人脸修复、解码和视频编码，不依赖 VHS / VideoHelperSuite，也不要求另外安装 MiniMax H3 Chunk—Star7 插件。

工作站接收 ComfyUI 画布中的模型、文本编码器、视频 VAE、音频 VAE，以及素材库输入。模型权重仍由使用者准备。Python 库依赖会在 `requirements.txt` 中明确列出；它们与额外的 ComfyUI 节点插件是不同的。

## 素材和分镜

素材使用稳定 ID，镜头描述通过 `@` 引用。普通素材改名不会替换提示词里的普通文字。分镜支持导入、检查、导出、插入与拖动排序。

后台生成支持当前镜头、批量选择和继续生成全部；查看队列可以检查顺序及一采、二采、修脸阶段。浏览器刷新后恢复后台任务状态，关闭 ComfyUI 服务会中断正在运行的任务，已保存成品保留。

参数修改应只由明确的镜头设置触发。普通连续性参考的前段画面变化单独提示，不自动连锁重跑；智能首尾帧使用上段尾帧时，实际输入变化需要更新。已有二采/修脸成品不会仅因取消开关而自动降级。

## 数据边界

本地运行数据位于 `data/`，按项目分别保存配置、素材、队列记录和辅助缓存。成品视频保存到 ComfyUI 的 `output/Star7-Director/年月日/`。

源码仓库不包含本地项目、私人素材、模型权重、缓存、日志或生成视频。更新代码时应保留已有 `data/`。分享普通工作流只携带配置与素材引用；项目包用于携带素材，不打包模型、成品或 latent 缓存。
